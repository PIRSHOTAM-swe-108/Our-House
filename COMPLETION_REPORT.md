## 🔧 Technical Implementation

### Database Structure
```javascript
State.sharedExpenses = [
  {
    id: timestamp,
    item: string,
    amount: number,
    category: string,
    notes: string,
    receipt: base64,
    addedBy: string,
    date: ISO8601,
    month: number,
    year: number
  }
]

State.payments = [
  {
    id: timestamp,
    from: string,
    method: string,
    amount: number,
    date: ISO8601,
    status: 'pending'|'completed',
    details: object
  }
]
```

### Key Algorithms
```
Fair Share = Total Expenses / Number of Members

Balance = Amount Spent - Fair Share
(positive = owed money, negative = owes money)

Settlement Algorithm:
1. Identify debtors (negative balance)
2. Identify creditors (positive balance)
3. Match smallest with smallest
4. Calculate minimum transfers
5. No circular transfers
6. Optimal solution
```
